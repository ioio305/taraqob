# Taraqob SPX OTM — مشروع LEAN

خوارزمية QuantConnect LEAN تطبّق استراتيجية «ترقّب» لخيارات SPX خارج المال، قارئةً
القواعد من `strategy_spec.json` (المُولّد من مصدر TS الواحد) وإعدادات التشغيل من
`run_config.json`. انظر `../../docs/strategy-lab.md` للصورة الكاملة.

## الملفات
- `main.py` — الخوارزمية (خارج المال فقط + نطاق DTE حسب الأفق + خروج من حركة الأصل + تكاليف صريحة).
- `strategy_spec.json` — القواعد والنطاقات ونموذج التكاليف (**مُولّد**، لا يُحرَّر يدويًا).
- `run_config.json` — يكتبه المُشغّل لكل تشغيل (الفترة/الدقّة/التكاليف).
- `test_parity.py` — اختبار تطابق خالص (بلا LEAN) يقارن قرار الدخول بالجانب TS.

## توليد المواصفة (مصدر واحد)
```bash
npx tsx scripts/lab/gen-spec.ts
```

## اختبار التطابق (لا يحتاج LEAN ولا Docker)
```bash
python lean/taraqob_spx_otm/test_parity.py
```

## تشغيل اختبار حقيقي (يتطلب أدوات + بيانات مدفوعة)
1. ثبّت الأداة المجانية: `pip install lean` (محرك LEAN مفتوح المصدر، Apache-2.0).
2. شغّل Docker Desktop (المحرك يعمل داخل حاوية).
3. **بيانات خيارات SPX تاريخية حقيقية** في مجلد بيانات LEAN — **مدفوعة وغير قابلة لإعادة
   التوزيع** (ترخيص المحرك ≠ ترخيص البيانات). تتطلب موافقة المالك واشتراك بيانات.
4. ثم: `lean backtest lean/taraqob_spx_otm`

بلا الخطوة (3) لن تُنتج الخوارزمية صفقات، ويُبلَّغ ذلك كـ `insufficient_data` —
لا رقم ملفّق. **نجاح البناء أو ظهور الواجهة ليس دليل نجاح المحرك.**
