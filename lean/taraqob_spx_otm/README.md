# SPXW decision replay for LEAN

The algorithm replays point-in-time plans generated by the existing TypeScript
selection, strategy and sizing functions. It does not generate a second Python
market-direction signal. See [the integration guide](../../docs/strategy-lab.md).

Required per-run inputs (materialized by the private worker):
- run_config.json: validated account, period, expiry band and cost assumptions.
- strategy_spec.json: generated by npm/tsx scripts/lab/gen-spec.ts.
- replay_decisions.json: selected plans plus run/data/engine provenance.

The worker runs the licensed CLI with Local data, a zero purchase limit,
an existing pinned Docker image and a fresh output directory. It does not
download paid data or place brokerage orders.

Tests: `python -X utf8 lean/taraqob_spx_otm/test_parity.py`.
These exercise the same pure rules imported by main.py. They are software tests,
not evidence of native LEAN execution or of trading profitability.

Quote-close execution is used; do not describe it as reconstruction of intrabar
high/low ordering. Only PM-settled SPXW is included. Far-expiry inputs are
research configurations and still need independent data/calibration.
