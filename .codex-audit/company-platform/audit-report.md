# تدقيق منصة الشركات مقابل منصة SPX

التاريخ: 2026-07-29

## النطاق

- منصة الشركات المنشورة: الماسح وتفاصيل الفرصة وتحليل سهم TSLA.
- منصة SPX المنشورة: الداشبورد وتوصية اليوم.
- التقييم بصري وتجريبي، مع مراجعة حالة المستودع المحلي.

## خطوات التدقيق

1. الماسح `/stocks` — يعمل ويعرض 12 فرصة مرتبة.
2. فتح تفاصيل TSLA — يعمل ويعرض العقد والسبب والدخول والهدف والوقف.
3. تحليل TSLA `/stocks/analyze?symbol=TSLA` — يعمل ويعرض الشارت والتحليل الفني والعقود.
4. داشبورد SPX `/v2` — يعمل ويعرض رحلة قرار متكاملة ومداخل أدوات متعددة.

## أهم النتائج

### نقاط قوة منصة الشركات

- ترتيب الفرص واضح وسريع المسح.
- وجود أنماط محافظ/متوسط/مغامر.
- لغة عربية مباشرة، مع سبب وخطوة تالية.
- خطة عقد عملية: دخول وهدف ووقف.
- تحليل فني وشارت وأخبار على مستوى السهم.
- موقف صادق من المعايرة: لا توجد دعوة شراء قبل التحقق التاريخي.

### فجوات رئيسية

- الملاحة المنشورة تعرض الماسح وتحليل السهم فقط، بينما SPX يوفّر خطة اليوم، الشارت الذكي، تحليل العقد، الإشارات، رادار الأموال، مرصد العقود، المحفظة التجريبية، الدفتر، مساعد الخروج، والشارت المتقدم.
- صفحة الشركات تبدأ بقائمة رموز، لا بقرار يومي موحّد يشرح أفضل فرصة ولماذا هي الأولى.
- الأدلة معروضة كوسوم عامة ولا توجد لوحة اتفاق مستقلة أو وزن لكل دليل.
- لا توجد متابعة كاملة بعد التوصية: تنبيهات حالة، محفظة تجريبية، سجل صفقة، ومساعد خروج.
- لا توجد ذاكرة أداء ظاهرة توضح نسبة النجاح والعائد المتوقع والعينة التاريخية حسب النمط والسهم.
- كثافة الرموز والاختصارات أعلى من مستوى اللغة العربية المبسطة المستهدف.

### تناقضات وثقة البيانات

- شاشة TSLA أظهرت السعر اليومي والتغير `+0.00%` وأعلى/أدنى اليوم `0 / 0`، ما يعني أن حالة البيانات غير مكتملة لكنها لا تُعرض بوضوح كبيانات ناقصة.
- التحليل الفني وصف TSLA بأنه هابط وقوة `10/100` ويدعم PUT، بينما العقد الأول المعروض كان CALL.
- الصفحة عرضت في الوقت نفسه أقوى منطقة كـ `طلب / CALL` مع تحليل عام هابط؛ يلزم طبقة حسم تفسّر التعارض.
- ظهر عقد ينتهي خلال `0 يوم` بعد الإغلاق، ويجب منع تقديمه كخطة قابلة للتنفيذ أو وصفه بوضوح كمنتهي/غير قابل للتداول.
- تحذير الأرباح “غير مؤكد” يضع عبء التحقق على المستخدم بدل إظهار مصدر وتاريخ آخر تحديث ودرجة ثقة.

## خارطة التطوير المقترحة

### P0 — الثقة قبل التوسع

1. إضافة بوابة صلاحية البيانات قبل عرض أي فرصة.
2. منع العقود المنتهية أو غير القابلة للتداول.
3. إضافة محرك حسم التعارض بين الاتجاه الفني، التدفقات، مناطق العرض/الطلب، والعقد المختار.
4. إظهار مصدر البيانات ووقت التحديث وحالتها: حي، متأخر، ناقص، مغلق.
5. عدم إظهار سعر أو تغير صفري كأنه رقم حقيقي.

### P1 — رحلة قرار بمستوى SPX

1. بناء “قرار الشركات اليوم” مع أفضل فرصة واحدة وثلاث بدائل.
2. بطاقة موحدة: ملخص القرار، لماذا الآن، ما الذي يؤكد، ما الذي يلغي، الدخول، الأهداف، الوقف، المدة، حجم المركز.
3. شريط سياق السوق: SPX/VIX والقطاع والأرباح والأخبار وحالة الجلسة.
4. ربط التوصية مباشرة بالشارت، تحليل العقد، الأخبار، التدفقات، والسجل.
5. إضافة حالات واضحة: انتظر، جاهزة، دخلت، هدف أول، حرّك الوقف، خرجت، أُلغيت.

### P2 — تعدد التحليل

1. التحليل الفني متعدد الأطر.
2. تحليل العقد والسيولة والسبريد وGreeks وIV.
3. تحليل الأرباح والأخبار والمشاعر.
4. تحليل القطاع والسوق والارتباط بـ SPX.
5. تحليل التدفقات غير المعتادة.
6. سيناريو صاعد/هابط/محايد مع شروط انتقال واضحة.

### P3 — الاحترافية والمتابعة

1. تنبيهات مرتبطة بأحداث الخطة، لا بالسعر فقط.
2. محفظة تجريبية ودفتر صفقات ومساعد خروج للشركات.
3. بطاقة مشاركة موحدة للتوصية.
4. سجل أداء علني حسب السهم والنمط ونوع العقد.
5. شرح قابل للتوسيع للمبتدئ، وتفاصيل كمية للمحترف.

## حدود التدقيق

- الحساب المتاح في منصة الشركات أظهر ميزات الباقة الحالية فقط.
- صفحات الأخبار وتقويم الأرباح والتدفقات موجودة كتغييرات محلية غير ملتزمة في المستودع، ولم تكن ضمن النسخة المنشورة التي تم التقاطها.
- فحص الوصول بلوحة المفاتيح وقارئات الشاشة والتباين يحتاج اختباراً منفصلاً.
