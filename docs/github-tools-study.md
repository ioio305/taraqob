# دراسة: أقوى أدوات التحليل والتوصيات في GitHub — وما يناسب ترقّب

> التاريخ: 2026-11-21. النجوم والنشاط من GitHub مباشرة. ترقّب = Next.js/TypeScript على Vercel + Supabase + Tradier/Yahoo/سهمك.
> القاعدة: نأخذ **الأفكار والبيانات** لا المحرّكات الكاملة (أغلبها Python)، ولا نغيّر عتبات المعايرة بالتخمين.

## تنبيه عاجل ظهر أثناء البحث
**CBOE حجب بياناته المؤجلة المجانية عن التطبيقات منذ 2026-11-20** (تحققتُ: `cdn.cboe.com/.../_SPX.json` → 403 من Cloudflare).
في ترقّب هو **مصدر احتياطي** فقط (Tradier أولاً) في: `gammaExposure.ts` (جاما SPX)، `cboe.ts` (سلسلة SPX عبر marketData)، `stockData.ts` (سلاسل الأسهم/الصناديق).
الأثر: عند غياب Tradier تسقط جاما إلى لا شيء وتسقط السلاسل إلى Black-Scholes التركيبية. البديل الذي اعتمدته Edge-GEX-Lab: OCC للعقود المفتوحة (لكن شروطه تمنع الاستخدام التجاري) أو Alpaca (مجاني، يغطي SPX).

## لا تناسب ترقّب
- **ai-hedge-fund** (65k): تعليمي، يحتاج بيانات مدفوعة + نموذج لغوي لكل قرار، أمريكي أساسي فقط.

## الأولوية المقترحة
1. **استبدال احتياطي CBOE** (عاجل — مكسور منذ أمس).
2. **حفظ لقطات جاما** يومياً ⇒ أساس لمعايرة جدران جاما.
3. **الشارة الشرعية** للسوق السعودي — بعد إذن مركز المقاصد.
4. **الرأي المعاكس** في مجلس القرار + مراجعة تسرّب المستقبل في التقييم.
5. **فلتر حالة السوق** (مدرّب الانكشاف) لآلة الزمن والتوصيات.
