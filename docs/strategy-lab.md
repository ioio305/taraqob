# مختبر الاستراتيجيات + تكامل محرك LEAN

> فرع معزول `codex/lean-strategy-lab` — محليًا، بلا نشر ولا مساس بالإنتاج.
> اقرأ أولًا `docs/platforms.md` وذاكرة المشروع. آخر تحديث: 2026-11-08.

## ما هذا؟
خدمة بحث/اختبار تاريخي لاستراتيجيات ترقّب عبر محرك **QuantConnect LEAN**، **منفصلة
تمامًا عن طلبات واجهة المنصة** (التوصيات الحيّة لا تمرّ بها)، مع واجهة «مختبر
الاستراتيجيات» عربية RTL تعرض النتائج الموثّقة بحالات صريحة وتمييز واضح
تاريخي/ورقي/حقيقي.

## الفرق الجوهري عن المِحراث القائم
`scripts/backtest.ts` يختبر **قرار اتجاه المؤشر** (هل لمس المؤشر الهدف قبل الوقف)،
وهذا **ليس إثباتًا لربحية العقد** — وهو بالضبط ما تحذّر منه المهمة. المختبر الجديد
يوجّه التقييم إلى **أسعار عقود حقيقية** داخل LEAN (bid/ask، مضاعف، انتهاء، تسوية،
رسوم، فرق، انزلاق)، لا حركة المؤشر وحدها.

## المعمارية (ملفات جديدة فقط — لم يُمسّ أي ملف أساسي محمي)
```

  strategySpec.test.ts  اختبار تطابق TS (يعيد استخدام mandatoryFilter)
```

## تطابق القواعد (مُتحقَّق منه)
القاعدة تُكتب مرة واحدة في `strategySpec.ts` وتُستهلك من طرفين:
- **TS**: `strategySpec.test.ts` يمرّر الحالات عبر `recommendCore.mandatoryFilter` نفسه الذي
  تستخدمه المنصة → **3 اختبارات ناجحة**.
- **Python**: `test_parity.py` يقرأ `strategy_spec.json` + نفس الحالات → **9/9 تطابق كامل**.
البوابة المُختبَرة: خارج المال فقط + نطاق سعر الطلب المتوازن + نطاق DTE حسب الأفق.

## الآجال الزمنية (مفصولة صراحةً)
- **تاريخ انتهاء العقد (DTE):** من الأفق — مغامر 0–1، متوسط 2–5، محافظ 7–45.
- **مدة الاحتفاظ المتوقعة:** يحدّدها الخروج من حركة الأصل (هدف/وقف)، لا الانتهاء.
- **إطار التحليل:** دقّة بيانات المحرك (دقيقة/ساعة/يومي) — مستقل عن الاثنين.
لا تُعمَّم إعدادات العقود القريبة على البعيدة؛ كل أفق يُقيَّم مستقلًا بنطاق DTE خاص.

## الحالات (واجهة الاتصال)
`pending` → `running` → `completed` | `failed` | `insufficient_data`. كل تشغيل يُحفظ مع:
إصدار الاستراتيجية، الإعدادات، مصدر البيانات ودقّتها وفترتها، نموذج التكاليف، وبصمة
المحرك — فيكون **قابلًا لإعادة الإنتاج والمقارنة**.

## الاشتراكات والصلاحيات
- الحد الأدنى: **إيدج** (ويشمل **ألفا**) — ثابت مركزي `LAB_MIN_TIER`.
- الحماية **على الخادم وطبقة البيانات**: `layout.tsx` يعيد التوجيه، وواجهتا الـAPI تُعيدان
  403 بلا بيانات لمن دون إيدج. راية `SHOW_STRATEGY_LAB` لإخفاء الرابط بصريًا فقط.
- تحذيرات جودة البيانات والمخاطر والتصنيف (تاريخي/ورقي/حقيقي) تُعرض للجميع المصرّح لهم.

## الترخيص والتكاليف (مهم)
- **محرك LEAN:** مفتوح المصدر Apache-2.0. أداة `lean` CLI مجانية (`pip install lean`).
- **بيانات الخيارات:** **منفصلة ومدفوعة وغير قابلة لإعادة التوزيع** — ترخيص المحرك ≠ حق
  استخدام/توزيع البيانات. تشغيل LEAN CLI مع بيانات QuantConnect يتطلب خطة مدفوعة، وبيانات
  خيارات SPX التاريخية الحقيقية تحتاج اشتراك بيانات وموافقة المالك.
- **لم تُشترَ أي خدمة ولم يُطلب أي مفتاح.** لا جدولة ولا أتمتة ولا أوامر حقيقية.

## ما يلزم لتشغيل اختبار حقيقي (بموافقة المالك)
1. `pip install lean` (مجاني).
2. تشغيل Docker Desktop (مثبّت محليًا لكن خدمته متوقفة الآن).
3. **اشتراك/مصدر بيانات خيارات SPX تاريخية حقيقية** في مجلد بيانات LEAN (`LEAN_DATA_DIR`
   أو `lean/data`) — **هنا تقع التكلفة والموافقة المطلوبة**.
4. التوليد ثم التشغيل:
   ```bash
   npx tsx scripts/lab/gen-spec.ts
   python lean/taraqob_spx_otm/test_parity.py     # تطابق (بلا LEAN)
   lean backtest lean/taraqob_spx_otm              # اختبار حقيقي (يحتاج 1–3)
   ```

## ما تحقّق فعليًا مقابل ما ينتظر البيانات
| العنصر | الحالة |
|---|---|
| تطابق القواعد TS↔Python من مصدر واحد | ✅ مُختبَر (3 + 9 نجاح) |
| توليد المواصفة، الحفظ، إعادة الفتح، واجهة الحالات | ✅ يعمل محليًا |
| مسار `insufficient_data` الصادق (بلا تلفيق) | ✅ هو السلوك الحالي للبيئة |
| البوابة على الخادم وطبقة البيانات (إيدج) | ✅ مطبّقة |
| **استدعاء LEAN فعلي + تقييم P/L بعقود حقيقية** | ⛔ ينتظر: Docker مُشغَّل + بيانات خيارات مدفوعة |

**نجاح البناء أو ظهور الواجهة ليس دليل نجاح المحرك أو صحة الأداء المالي.** فرع التحليل في
`leanRunner.parseLeanResult` مكتوب وجاهز لكنه لم يُشغَّل بعد ببيانات حقيقية؛ يُفعّل متى
توفّرت البيانات والموافقة.

## حدود منع المعلومات المستقبلية
الاختيار داخل `main.py` يعتمد على السلسلة المتاحة وقت القرار فقط (`slice`)، والخروج يُفترض
فيه لمس الوقف أولًا داخل الشمعة (محافظ). التقييم الدقيق للمس داخل الشمعة يحتاج دقّة دقيقة
أو أدق — ولهذا الدقّة الافتراضية «دقيقة».
